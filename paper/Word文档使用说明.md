## 📝 格式调整建议

### 1. 标题格式

如果期刊模板要求不同的标题格式：

1. 选中标题
2. 右键 → 样式 → 修改样式
3. 调整字体、字号、颜色等

### 2. 正文格式

如果需要调整正文格式：

1. 选中正文
2. 段落 → 行距 → 设置为1.5倍或其他
3. 段落 → 缩进 → 首行缩进2字符

### 3. 表格格式

如果需要调整表格样式：

1. 选中表格
2. 表格工具 → 设计 → 选择样式
3. 或手动调整边框、底纹等

### 4. 页眉页脚

如果需要添加页眉页脚：

1. 插入 → 页眉/页脚
2. 输入内容（如期刊名称、页码等）
3. 设置格式

## 🔧 常见问题

### Q1: 如何修改文档内容？
**A**: 有两种方法：
1. 直接在Word中编辑（推荐）
2. 修改`generate_word_paper.py`脚本后重新生成

### Q2: 如何添加更多表格？
**A**: 在Word中：
1. 插入 → 表格
2. 选择行列数
3. 输入数据
4. 设置格式

或在脚本中使用`add_table()`函数。

### Q3: 如何插入图片？
**A**: 
1. 插入 → 图片 → 此设备
2. 选择图片文件
3. 调整大小和位置
4. 添加图注

### Q4: 格式不符合期刊要求怎么办？
**A**: 
1. 参考期刊模板
2. 使用"格式刷"复制样式
3. 或手动调整格式

### Q5: 如何导出为PDF？
**A**: 
1. 文件 → 另存为
2. 选择"PDF"格式
3. 保存
