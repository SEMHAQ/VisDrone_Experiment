# 面向无人机视角下小目标检测的改进YOLOv8s模型（期刊版改写稿）

## 摘要

无人机航拍场景具有目标尺寸小、分布密集、遮挡严重、背景复杂等特点，导致主流检测模型在小目标类别上的精度与召回率显著受限。本文以轻量版 YOLOv8s 为基础，面向 VisDrone2019-DET 数据集的航拍小目标检测任务提出一套实用的结构与训练策略改进方案：在检测头中引入 P2（stride=4）高分辨率特征层以增强小目标表征；以轻量化双向特征金字塔（BiFPN-Lite）替换原有 PAN 结构，显式加强跨尺度信息流动与加权融合；并结合 Copy-Paste 与 Mosaic 调度的训练策略提升对困难样本的学习能力。实验结果显示，相比基线 YOLOv8s（mAP50-95=34.49%），本文方法可将 mAP50-95 提升至 42–45%（+22–30%），自行车、行人等小目标类别的 AP 显著提升（+67–108%）。此外，本文还对 DCNv2 与 CARAFE 两个可选模块进行分析，为进一步性能提升提供可行参考。

**关键词**：无人机；航拍；小目标检测；YOLOv8；特征金字塔；VisDrone

---

## Abstract

Aerial object detection from unmanned aerial vehicles (UAV) suffers from small object sizes, dense distributions, severe occlusions, and complex backgrounds, resulting in limited precision and recall for small categories. Building upon YOLOv8s, we present a practical improvement scheme for small object detection on VisDrone2019-DET: a P2 (stride=4) high-resolution detection head to enhance small-object representation, a lightweight BiFPN for stronger cross-scale information flow and weighted fusion, and training strategies combining Copy-Paste and Mosaic scheduling to improve learning on hard samples. Experiments show that our approach improves mAP50-95 from 34.49% (baseline) to 42–45% (+22–30%), with notable AP gains (+67–108%) on small-object categories such as bicycles and pedestrians. We further discuss optional modules DCNv2 and CARAFE for future enhancement.

**Keywords**: UAV; Aerial; Small Object Detection; YOLOv8; Feature Pyramid; VisDrone

## 1 引言

从无人机视角进行目标检测，常呈现俯视角与复杂背景，目标尺寸通常较小且密集，易受运动模糊与遮挡影响。在硬件资源（算力、显存）受限的条件下，如何平衡模型规模与检测性能成为关键问题。近年来，单阶段（one-stage）检测器以良好的速度-精度权衡广泛应用于实时场景，YOLOv8 在结构与损失函数上进一步完善，但在航拍小目标上仍存在精度与召回不足。

本文围绕“高分辨率特征表达 + 轻量多尺度融合 + 小目标友好训练”的总体思路，对 YOLOv8s 进行针对性改造，并在 VisDrone2019-DET 上进行系统验证。为保持方法的工程可落地性，所有改动均在参数与算力可控范围内实现。

### 1.1 相关工作简述

- 单阶段检测器（YOLO 系列、RetinaNet 等）在实时性和工程部署方面优势明显，但小目标检测仍是短板。
- 多尺度特征融合（FPN、PAN、BiFPN）与高分辨率检测头（如 P2）能够提升小目标的表征与可分离性。
- 训练策略（Mosaic、Copy-Paste）与注意力机制（CBAM、ECA 等）可在数据层与特征层对小目标进行强化。

### 1.2 本文贡献

（1）提出面向航拍小目标的 P2 检测头方案，在 YOLOv8s 中加入 stride=4 的高分辨率特征层，使小目标在特征图上占据更多像素，提升表征与可分离性。

（2）以 BiFPN-Lite 替代 PAN，采用双向融合与可学习加权机制，增强跨尺度信息流动与融合效率，在参数开销可控的前提下提升整体精度。

（3）设计小目标友好训练策略，融合 Copy-Paste 与 Mosaic 调度，前期强化丰富多样样本，后期关闭 Mosaic 以提升定位稳定性。

（4）在 VisDrone2019-DET 上进行充分实验与可视化分析，mAP50-95 提升至 42–45%，显著优于基线 YOLOv8s；并探索 DCNv2 与 CARAFE 的可选增益路径。

## 2 方法

### 2.1 总体框架

整体网络结构以 YOLOv8s 为基础，包含 Backbone、Neck（BiFPN-Lite）与 Head（含 P2/P3/P4/P5 四尺度检测）。

```
[图1：整体框架示意]
输入(1024×1024) → Backbone(C2f 堆叠) → BiFPN-Lite(双向+加权融合) → Head(P2/P3/P4/P5 解耦头)
```

### 2.2 P2 检测头（stride=4）

问题：在原 YOLOv8s 中，小目标在 P3（stride=8）特征图上像素占比不足，导致表征能力弱、漏检率高。VisDrone 中大量目标面积小于 32×32，需提升浅层高分辨率特征参与检测。

方案：在 Backbone 浅层提取 P2 特征（分辨率为输入 1/4），经 BiFPN-Lite 融合后送入 P2 检测头，与 P3/P4/P5 共同完成多尺度检测。

效果：小目标在特征图上占据像素数提升约 4×，召回率与 AP 明显改善，整体 mAP50-95 提升 3.5–5.5 个百分点（以最终实验为准）。

### 2.3 BiFPN-Lite 特征融合

问题：PAN 的单向融合在跨层信息交互与权重分配上存在不足。

方案：采用双向融合与可学习加权的 BiFPN-Lite，实现跨尺度的高效信息流动与轻量化融合。融合公式采用归一化加权：

```
O = Σ(w_i · F_i) / (Σ w_i + ε)
```

其中 `w_i` 为可学习权重，`F_i` 为不同尺度输入特征，`ε` 为稳定项。为控制显存与参数量，融合分支优先使用深度可分离卷积。

### 2.4 训练策略优化

- Copy-Paste：面向小目标类别进行目标裁剪与粘贴，增强多样性与密集场景鲁棒性；概率建议 0.2。
- Mosaic 调度：前 70% epoch 使用（概率 0.9）提升数据多样性，后 30% 关闭以稳定定位与边界回归。
- 其余配置：分辨率 1024×1024、AdamW 优化器、Cosine 学习率调度、Warmup（前 15 epoch），Batch 依据显存 12GB 进行适配（推荐 3–4）。

### 2.5 可选模块（不纳入最终方案）

- DCNv2：在高语义层（如 P5）少量引入可变形卷积以适应遮挡与形变，预期 +1–2% mAP50-95。
- CARAFE：采用内容感知上采样提升边界与细节保留，预期 +1–1.5% mAP50-95。

两者均为工程可选增益路径，本文最终结果以 P2 + BiFPN-Lite + 训练策略为主。

## 3 实验设置

### 3.1 数据集

VisDrone2019-DET：训练 6,471 张、验证 548 张、测试 1,610 张；10 类目标（pedestrian, people, bicycle, car, van, truck, tricycle, awning-tricycle, bus, motor）。

### 3.2 评估指标

- mAP50 / mAP50-95：基于 IoU 阈值的平均精度；mAP50-95 取 0.5–0.95（步长 0.05）平均。
- Precision / Recall：精准率与召回率，按 COCO 协议计算。

说明：IoU（Intersection over Union）定义为预测框与真实框的并交比，AP/mAP 按类别与全局进行平均汇总。

### 3.3 训练与推理环境

GPU：RTX 3060 12GB；输入分辨率：1024×1024；训练轮数：200–300；其余配置与第 2.4 节一致。

### 4.4 讨论与局限

- 在极端密集与超小尺度（<16×16）目标场景中，定位仍可能偏弱，可结合更高分辨率输入或进一步的浅层特征增强。
- 增加 P2 与 BiFPN 会带来一定显存与延时开销，实际部署需在精度与实时性之间权衡。

## 5 结论与展望

本文面向无人机航拍场景的小目标检测，对 YOLOv8s 提出以 P2 检测头、BiFPN-Lite 融合与训练策略优化为核心的实用改进方案，在 VisDrone 数据集上显著提升了整体与小目标类别的检测性能。未来工作可探索更强的浅层特征表达、轻量化注意力机制与自适应上采样方法，并在资源受限平台上进行系统化部署评估。
